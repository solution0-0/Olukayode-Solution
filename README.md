# Olukayode Solution — Portfolio

A personal portfolio recreation based on the layout and visual style . The page keeps the same simple Freelancer-style structure: dark navigation, turquoise masthead and About section, white portfolio/contact sections, six portfolio tiles and project detail modals.

## Publish on GitHub Pages
1. Create a repository, e.g. `olukayode-portfolio`.
2. Upload all files and folders in this project to the repository root.
3. Open **Settings → Pages**.
4. Select **Deploy from a branch**, choose `main` and `/(root)`, then save.
5. GitHub Pages will provide your public website URL.

## Included
- `index.html` — page content and sections
- `style.css` — layout, typography, colours and responsive styling
- `script.js` — navigation and project detail modals
- `assets/img/profile-photo.png` — supplied profile photo
- `assets/img/portfolio/` — six project thumbnails
- `assets/Olukayode-Solution-CV.pdf` — supplied CV

External Google Fonts and Font Awesome are loaded from their CDNs. Internet access is required for those external font and icon resources.
